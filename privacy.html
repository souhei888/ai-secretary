ホームプライバシーポリシー利用規約

プライバシーポリシー

最終更新: 2026年11月12日

1. 対象

本ポリシーは、個人用ツール「AI秘書」（以下「本ツール」）におけるGoogleユーザーデータの取り扱いを定めます。本ツールの利用者は開発者本人のみです。

2. 取得するデータ

本人が許可した範囲で、Googleカレンダーの予定、Googleドライブのファイル（ドキュメント・スプレッドシート・スライドを含む）、Gmailのメール、Google Apps Scriptのソースコードを読み取り専用で取得します。作成・変更・削除・送信は行いません。

3. 利用目的

本人がDiscordで依頼した質問への回答（予定の確認、資料の検索・要約など）のためだけに利用します。広告、販売、第三者のプロファイリングには一切利用しません。

4. 保存と第三者提供

取得したデータは依頼への回答に必要な間だけ処理し、本人の管理するPC以外に保存しません。回答の生成のため、依頼内容と必要なデータの一部をAIモデル提供事業者（Anthropic）のAPIへ送信します。それ以外の第三者には提供しません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含むGoogle API Services User Data Policyに準拠します。

6. アクセスの取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」からいつでもアクセスを取り消せます。
